# JananiGuide
Guideline-grounded, multilingual decision support for frontline maternal and child health workers in India.
Answers only from official MoHFW guidelines, flags danger signs with deterministic rules, cites the source for every answer, and refers to a doctor when unsure. Decision support, not diagnosis.

Status: in development (Code for a Billion, Bharat Agentic-AI Hackathon 2026).
